# Welcome to Ivory Garden

Ivory Garden is a warm, paper-light theme for Obsidian. It's a recolour of [Minimal](https://github.com/kepano/obsidian-minimal) by [@kepano](https://twitter.com/kepano), designed for long reading sessions with reduced eye strain.

## Quick tour

Open the files in this vault to see every feature in context:

1. **[[Typography]]** — headings, paragraphs, inline formatting, links
2. **[[Lists and Tasks]]** — bullet lists, numbered lists, task lists, nested lists
3. **[[Tables]]** — basic tables, striped rows, row numbers, dataview tables
4. **[[Callouts]]** — every callout type
5. **[[Code]]** — inline code, code blocks, syntax highlighting
6. **[[Quotes and Highlights]]** — blockquotes, nested quotes, text highlights
7. **[[Embeds and Links]]** — transclusions, embeds, backlinks

## What makes Ivory Garden different?

Most light themes default to pure white backgrounds with pure black text. After a few hours, that's harsh on the eyes. Ivory Garden takes a different approach:

- **Ivory paper, not white** — backgrounds use `#FAF5F0` (warm ivory) instead of `#FFFFFF`
- **Cocoa text, not black** — body text uses `#3E2723` (deep cocoa brown) instead of pure black
- **A single cool accent** — cobalt blue `#0B68DA` for links and interactive elements
- **A signature gold glow** — text highlights use muted gold `#C49A3C`, not yellow

> The result feels like an ivory garden at golden hour — soft, luminous, and contemplative.

## Try this

Toggle between **Light** and **Dark** mode (Settings → Appearance → Base color scheme) to see both Ivory Garden (light) and Midnight Garden (dark). The dark variant uses espresso-black backgrounds with warm ivory text, and a brighter gold glow that survives the darkness.

For full feature control, install the **Minimal Theme Settings** plugin. For granular color customization, install **Style Settings**.
