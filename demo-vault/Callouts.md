# Callouts

How Ivory Garden handles Obsidian callouts.

## Default (filled) style

> [!note] Note
> This is a note callout. The left border uses the cobalt accent color, and the title inherits the accent.

> [!info] Information
> This is an info callout. Same styling as note, just a different icon.

> [!tip] Tip
> Tips use the same callout structure but a different icon.

> [!success] Success
> Success callouts indicate a positive outcome.

> [!warning] Warning
> Warnings signal something to be careful about.

> [!failure] Failure
> Failure callouts indicate something went wrong.

> [!danger] Danger
> Danger callouts are for critical warnings.

> [!bug] Bug
> Bug callouts flag known issues.

> [!example] Example
> Example callouts illustrate a concept.

> [!quote] Quote
> Quote callouts render blockquotes inside a callout container.

> [!abstract] Abstract
> Abstract callouts summarize content.

## Collapsible callouts

> [!note]- Collapsed by default
> Click the triangle to expand this callout. Useful for hiding detailed information.

> [!note]+ Expanded by default
> This callout starts expanded. Click the triangle to collapse it.

## Callouts with formatting

> [!tip] Tip with **bold** and *italic*
> You can use **bold**, *italic*, `inline code`, [links](Welcome), and ==highlights== inside callout titles and bodies.
>
> Multiple paragraphs work too.
>
> - And bullet lists
> - Inside the callout body

## Outlined callout style

Add the `callouts-outlined` class to a note (or enable it globally via Minimal Theme Settings) to switch to the outlined style — the title floats above the border, and the body becomes transparent.

> [!note] Outlined note
> This is what the outlined style looks like. The title sits above the border with a small-caps treatment.
