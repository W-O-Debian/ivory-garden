## Paragraphs

This is a paragraph of body text. Ivory Garden uses `#3E2723` (deep cocoa brown) for body text instead of pure black. The contrast against the ivory background is still excellent, but the page reads softer — more like a printed book, less like a screen.

This is a second paragraph. Notice the paragraph spacing — comfortable but not excessive. The line height is 1.5, which works well for both reading and editing. Long paragraphs don't feel cramped, and short paragraphs don't feel lost.

## Inline formatting

You can use **bold text** for emphasis, *italic text* for titles, and ***bold italic*** for both. Inline code uses `backticks` and renders in a warm coffee color (`#5D4037`) against a soft sand background.

Links render in cobalt blue (`#0B68DA`) — like [this internal link](Welcome) or [this external link](https://obsidian.md). Hovered links darken to `#094FA6`.

==Highlights== use the signature muted gold glow (`#C49A3C` at 35% opacity) — the palette's namesake. ==Try highlighting this text== to see how it stands out without shouting.

## Emphasis combinations

- **Bold with `inline code`** inside
- *Italic with [a link](Welcome) inside*
- ==Highlighted with **bold** inside==
- `code` with ==highlight== after
- A [link](Welcome) with *italic* after

## Special characters

Ivory Garden supports the full range of Unicode: em-dashes (—), en-dashes (–), ellipses (…, curly quotes ("smart"), arrows (→ ← ↑ ↓), and mathematical symbols (√ ∑ ∫ π ≅).
