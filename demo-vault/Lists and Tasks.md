# Lists and Tasks

How Ivory Garden handles lists of every kind.

## Bullet lists

- First-level bullet
- Second item
  - Nested bullet (second level)
    - Third-level nested bullet
  - Back to second level
- Third item

## Numbered lists

1. First item
2. Second item
   1. Nested numbered item
   2. Another nested item
3. Third item

## Mixed lists

1. Numbered item
   - Bullet inside numbered
     - Deeper bullet
2. Another numbered item
   1. Nested numbered
   - Bullet again

## Task lists

Task lists use a circular checkbox style by default. Completed tasks get a strikethrough and the cobalt accent fills the checkbox.

- [ ] Uncompleted task
- [ ] Another uncompleted task
- [x] Completed task — strikethrough applied
- [x] Another completed task
- [ ] A third uncompleted task

## Definition-style lists

Term one
: Definition for term one, wrapped in a blockquote-style format.

Term two
: Definition for term two, with **bold** and *italic* formatting inside.

## List with formatting

- **Bold list item** with extra text
- *Italic list item* with `inline code`
- List item with [a link](Welcome) and ==a highlight==
- List item with a footnote[^1]

[^1]: Footnotes inside lists work too.
