# Ivory Garden — Demo Vault

This vault contains sample notes that showcase every Ivory Garden feature in context. Open it in Obsidian with Ivory Garden enabled to see how the theme handles each element.

## Files

- `Welcome.md` — overview and quick tour
- `Typography.md` — headings, paragraphs, inline formatting, links
- `Lists and Tasks.md` — bullet lists, numbered lists, task lists, nested lists
- `Tables.md` — basic tables, striped rows, row numbers, dataview tables
- `Callouts.md` — every callout type
- `Code.md` — inline code, code blocks, syntax highlighting
- `Quotes and Highlights.md` — blockquotes, nested quotes, text highlights
- `Embeds and Links.md` — transclusions, embeds, backlinks

## Tips

- Toggle between **Light** and **Dark** mode (Settings → Appearance → Base color scheme) to see both Ivory Garden and Midnight Garden.
- Toggle between **Editing** and **Reading** mode (Cmd/Ctrl + E) to see how the theme handles both views.
- Install the **Minimal Theme Settings** plugin for feature toggles (focus mode, table styles, tab styles, etc.).
- Install the **Style Settings** plugin for granular color customization.
